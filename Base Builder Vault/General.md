___
Game takes place on an asteroid / asteroid cluster / asteroid belt and end goal is to escape after a crash landing.
There are [[Resources]] scattered around the place, some of which can be extracted and processed manually while others need external tools. (eg. worker bots, processing facilities, mining implants)
Starting facilities are the broken down ship's hull and a laser mining tool for basic resources.
The ship is an actual building that can be entered, built in and repaired.
