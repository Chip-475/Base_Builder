The player will enter build mode by pressing a button on the botton left of the screen.
Once pressed the player will be able to select the building he wants to place if the [[Inventory]] contains the necessary [[Resources]].
After placing a building a free [[Carrier Bot]] will go and place all the resources in a WIP near and only after a free [[Builder Bot]] will go to the place and start building.
